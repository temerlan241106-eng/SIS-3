# AI Usage

AI tools were used during the development of the SportHub Android application.

## Used for

AI assistance was used for:
- explaining Jetpack Compose concepts;
- helping structure Compose screens;
- creating reusable composables;
- checking Kotlin and Compose code;
- troubleshooting build and Git issues;
- improving UI structure and readability;
- preparing project documentation.

## Developer Responsibility

All generated code was reviewed, tested, and integrated into the Android Studio project by the developer.

The developer verified that the project builds successfully and that the implemented screens and navigation work as expected.

## Technologies

The project uses:
- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
