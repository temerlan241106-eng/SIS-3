# SportHub

Android application built with Kotlin and Jetpack Compose.

## Description

SportHub is a simple sports application that displays athletes and their information.

The application includes:
- Athletes screen
- Athlete details screen
- Favorites screen
- Sports horizontal list
- Athlete vertical list
- Navigation between screens
- Empty favorites state
- Dark mode support
- Reusable Compose components

## Technologies

- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
- Android Studio

## Screens

### Athletes
Main screen with a list of athletes and available sports.

### Athlete Details
Displays detailed information about the selected athlete.

### Favorites
Displays an empty state when no athletes have been added to favorites.

## Design

The application follows the general structure of the provided assignment sketch. The interface was implemented using Jetpack Compose and adapted into a modern Android UI.
